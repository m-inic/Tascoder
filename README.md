<strong>Tascoder</strong> is for posting tasks for colleagues within your workplace.

It's possible to post them with a due date, priority, as well as delete them, undo the tasks once you are registered with your credentials.

The app is also responsive, and showcases my technical skills in HTML, CSS, JS, React.js.

I've taken care of the basics (responsiveness, coloring, headings, menus) and advanced topics (login, DOM manipulation, form validation) which should be enough to take my learning journey to the next level.

Here is the website: https://tascoder.netlify.app/
